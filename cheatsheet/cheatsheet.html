herdr - panes, tabs, agents

PREFIX = press ctrl+b, let go, then press the key  ·  PREFIX ? shows all keys

Scroll up and copy text (no mouse)

PREFIX yStart copy mode (scroll back)
k / jUp / down 1 line
ctrl+u / ctrl+dUp / down half a screen
fn+↑ / fn+↓Up / down 1 screen
{ / }Up / down 1 paragraph
h / lLeft / right 1 character
w / b / eNext word / back / end of word
? text enterSearch up (fastest)
/ text enterSearch down
n / NNext / previous result
v or spaceStart selection
y or enterCopy and close
q or escClose, no copy
cmd+vPaste

ctrl+b does not page up in copy mode. Use ctrl+u

Example: copy an old error

  1. PREFIX y - copy mode
  2. ? error enter - search up
  3. n - next one up, if needed
  4. v - start selection, then j j e to grow it
  5. y - copy
  6. PREFIX l - go to the other pane, then cmd+v
